# 📜 Changelog

All notable changes to the Stone Paper Scissors Python project
are documented here.

## [1.0.0] - Initial Release

### 🎮 Original Game
- Added Stone Paper Scissors gameplay.
- Implemented player vs computer functionality.
- Added random computer choices.
- Implemented win, lose, and draw detection.
- Improved input validation.
- Added game exit functionality.

### 🚀 Enhanced Game
- Added colorful terminal interface using Colorama.
- Added interactive countdown animation.
- Implemented player and computer score tracking.
- Added draw tracking.
- Added multiple rounds.
- Added final scoreboard and winner announcement.

### 📚 Documentation
- Added professional README.md.
- Added GAME_GUIDE.md with gameplay instructions.
- Added requirements.txt for dependencies.
- Added .gitignore for Python projects.
