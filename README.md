# 🎮 Stone Paper Scissors Game — Python

A fun and interactive command-line Stone Paper Scissors game developed using Python.

This repository contains two versions of the game:
- Original Game — Developed by me
- Enhanced Game — Created with AI assistance

## 🚀 Features

### 🪨 Original Game
- Simple command-line gameplay
- Player vs Computer
- Random computer choices
- Win, Lose and Draw detection
- Input validation
- Exit option

### 🎨 Enhanced Game
- Colorful terminal interface
- Interactive countdown animation
- Score tracking system
- Multiple rounds
- Final scoreboard
- Winner announcement
- Input validation

## 🛠️ Technologies Used

- Python 3
- Random Module
- Time Module
- Colorama Library
- Git & GitHub

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/sagarmeena004/Stone-Paper-Scissors-Python.git
```

Navigate to the project:

```bash
cd Stone-Paper-Scissors-Python
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ How to Play

Run the original game:

```bash
python project_1.py
```

Or run the enhanced game:

```bash
python project1gpt.py
```

### Game Controls

| Input | Action |
|---|---|
| 1 | 🪨 Stone |
| 2 | 📄 Paper |
| 3 | ✂️ Scissors |
| 5 | Exit Game |

## 📜 Game Rules

- Stone beats Scissors
- Scissors beats Paper
- Paper beats Stone
- Same choices result in a draw
