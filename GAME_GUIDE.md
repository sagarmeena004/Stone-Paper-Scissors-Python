# 🎮 Stone Paper Scissors — Game Guide

## 📖 About the Game

Stone Paper Scissors is a classic game where a player competes against the computer.

The computer randomly selects Stone, Paper, or Scissors.

## 🎯 Game Controls

| Input | Choice |
|-------|--------|
| 1 | 🪨 Stone |
| 2 | 📄 Paper |
| 3 | ✂️ Scissors |
| 5 | ❌ Exit |

## 🏆 Winning Rules

- 🪨 Stone defeats Scissors.
- 📄 Paper defeats Stone.
- ✂️ Scissors defeats Paper.
- 🤝 Same choices result in a draw.
